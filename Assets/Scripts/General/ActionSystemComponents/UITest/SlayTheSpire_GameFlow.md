# 杀戮尖塔 (Slay the Spire) 游戏复刻文档

## 1. 游戏概述

杀戮尖塔是一款融合了卡牌构筑与 Roguelike 元素的单人策略游戏。玩家扮演一名冒险者，通过攀爬尖塔的方式逐步挑战更强大的敌人，收集卡牌并构筑卡组，最终击败塔顶的Boss。

## 2. 核心游戏流程

```
开始游戏 → 选择角色 → 进入地牢 → 探索地图 → 遭遇事件 → 战斗/事件处理 → 获得奖励 → 继续探索 → 击败Boss → 进入下一层 → 重复直到通关或死亡
```

## 3. 核心系统设计

### 3.1 角色系统

#### 3.1.1 角色属性

| 属性名称 | 说明 | 默认值示例 |
| :--- | :--- | :--- |
| 生命值 (HP) | 角色当前生命值，归零则死亡 | 80-100 |
| 最大生命值 | 角色最大生命值上限 | 80-100 |
| 能量 | 每回合可用能量，用于打出卡牌 | 3 |
| 护甲 | 抵挡伤害的护盾，回合结束时消失 | 0 |
| 金币 | 用于购买卡牌、遗物、药水 | 99 |
| 状态效果 | 各种增益/减益状态 | - |

#### 3.1.2 角色类型

- **战士 (Ironclad)** - 近战物理型，擅长防御和打击
- **静默者 (Silent)** - 敏捷型，擅长中毒和闪避
- **机器人 (Defect)** - 能量型，擅长使用球和法术

### 3.3 战斗系统

#### 3.3.1 战斗流程

```
开始战斗 → 抽牌阶段 → 玩家回合 → 敌人回合 → 循环直到一方死亡
```

#### 3.3.2 回合结构

1. **开始阶段**: 重置能量、护甲清零、应用回合开始效果
2. **抽牌阶段**: 从牌库抽 5 张牌
3. **行动阶段**: 打出卡牌、使用药水、结束回合
4. **结束阶段**: 弃掉手牌、应用回合结束效果

#### 3.3.3 伤害计算

```
实际伤害 = 基础伤害 × 伤害倍率 - 护甲
```

### 3.4 遗物系统

遗物是被动道具，提供各种永久效果。

| 遗物名称 | 效果 |
| :--- | :--- |
| 燃烧之血 | 每场战斗结束后恢复 6 点生命值 |
| 仪式匕首 | 每场战斗开始时获得 1 点能量 |
| 蛇戒指 | 战斗开始时随机获得 1 个药水 |

### 3.5 药水系统

药水是消耗品，在战斗内外使用。

| 药水类型 | 效果 |

| 力量药水 | 战斗中获得 2 点力量 |
| 敏捷药水 | 战斗中获得 2 点敏捷 |
| 能量药水 | 战斗中获得 2 点能量 |

| 事件类型 | 说明 | 示例 |
| :--- | :--- | :--- |

## 7. 游戏状态管理

### 7.1 状态机

```
MenuState → CharacterSelectState → MapState → EventState
                                            ↓
                                       BattleState
                                            ↓
                                      VictoryState / GameOverState
```

### 7.2 状态转换

| 当前状态 | 触发条件 | 下一状态 |
| :--- | :--- | :--- |
| Menu | 点击开始游戏 | CharacterSelect |
| CharacterSelect | 选择角色 | Map |
| Map | 选择节点 | Event / Battle |
| Event | 完成事件 | Map |
| Battle | 胜利 | Map |
| Battle | 失败 | GameOver |
| Map | 击败Boss | Map (下一层) |
| Map | 通关所有层 | Victory |

## 9. 技术架构

### 9.1 组件划分

```
Scripts/
├── Core/           # 核心游戏逻辑
│   ├── GameManager.cs
│   ├── BattleManager.cs
│   └── MapManager.cs
├── Characters/     # 角色系统
│   ├── Player.cs
│   ├── Enemy.cs
│   └── Boss.cs
├── Cards/          # 卡牌系统
│   ├── Card.cs
│   ├── CardDatabase.cs
│   └── CardEffect.cs
├── UI/             # 用户界面
│   ├── BattleUI.cs
│   ├── MapUI.cs
│   └── CardUI.cs
├── Data/           # 数据管理
│   ├── SaveManager.cs
│   └── ConfigLoader.cs
└── Events/         # 事件系统
    └── EventSystem.cs
```

### 9.2 设计模式

- **MVC模式**: 分离数据(Model)、视图(View)、控制器(Controller)
- **状态模式**: 管理游戏状态转换
- **工厂模式**: 创建卡牌和敌人实例
- **观察者模式**: 处理游戏事件通知
