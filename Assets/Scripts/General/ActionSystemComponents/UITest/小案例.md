1.我就制作两个角色，玩家和敌人

2.执行这个流程死亡后就不断复活重生继续执行

* **开始阶段**: 重置能量、护甲清零、应用回合开始效果
* **抽牌阶段**: 从牌库抽 5 张牌
* **行动阶段**: 打出卡牌、使用药水、结束回合
* **结束阶段**: 弃掉手牌、应用回合结束效果

3.战斗流程

```
开始战斗 → 抽牌阶段 → 玩家回合 → 敌人回合 → 循环直到一方死亡
```

4 遗物系统


遗物是被动道具，提供各种永久效果。

| 遗物名称 | 效果                          |
| :------- | :---------------------------- |
| 燃烧之血 | 每场战斗结束后恢复 6 点生命值 |
| 仪式匕首 | 每场战斗开始时获得 1 点能量   |

#### 3.1.1 角色属性

| 属性名称    | 说明                           | 默认值示例 |
| :---------- | :----------------------------- | :--------- |
| 生命值 (HP) | 角色当前生命值，归零则死亡     | 80-100     |
| 最大生命值  | 角色最大生命值上限             | 80-100     |
| 能量        | 每回合可用能量，用于打出卡牌   | 3          |
| 护甲        | 抵挡伤害的护盾，回合结束时消失 | 0          |
| 金币        | 用于购买卡牌、遗物、药水       | 99         |
| 状态效果    | 各种增益/减益状态              | -          |
